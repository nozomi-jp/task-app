# タスク管理アプリ 要件定義書

まずこのページだけ読めば、全体がつかめるようにしています。詳しい内容は、下の「文書の構成」から各ファイルを開いてください。

## 1ページ要約

| 項目 | 内容 |
| --- | --- |
| 何を作るか | リストとカードでタスクを管理する、Trello風のシンプルなWebアプリ（ボード1枚） |
| 誰が使うか | 自分ひとり。1台のパソコンで使う。ログインや共有はしない |
| 技術 | 画面：React ＋ JavaScript（Vite でビルド。Next.js は使わない）<br>バックエンド：Java 25 ＋ Spring Boot（Maven、Spring Data JPA、Flyway）<br>データベース：PostgreSQL（Docker で動かす） |
| 進め方 | 画面・バックエンド・データベースを最初から組み合わせて作る。サーバーを起動して `http://localhost:8080` を開く。まず3つがつながる最小の形を作り、機能を1つずつ足す |
| できること（13機能） | リストの表示・追加・名前変更・削除、カードの追加・編集・削除・移動・並べ替え、自動保存、カードの期限・優先度、期限順・優先度順の並べ替え |
| 作らないもの | ログイン、複数人での利用、複数ボード、ラベル（色）、元に戻す、スマートフォン表示、インターネットへの公開 |
| 守ること | 動かすときにCDNを使わない、自分のパソコンの中だけで動かす、パスワードをGitに入れない |
| 完成の判断 | 受入テストの「必須」の項目がすべて合格したら完成 |
| まだ決まっていないこと | Q-05 使うソフトとライブラリの具体的な版（ステップ1の開始時に決める） |
| 次にやること | ステップ1「開発環境を用意する」 |
