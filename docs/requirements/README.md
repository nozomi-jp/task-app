# タスク管理アプリ 要件定義書

まずこのページだけ読めば、全体がつかめるようにしています。詳しい内容は、下の「文書の構成」から各ファイルを開いてください。

## 1ページ要約

| 項目 | 内容 |
| --- | --- |
| 何を作るか | リストとカードでタスクを管理する、Trello風のシンプルなWebアプリ（ボード1枚） |
| 誰が使うか | 自分ひとり。1台のパソコンで使う。ログインや共有はしない |
| 技術 | 画面：React 19.3 ＋ TypeScript 7.0（Vite 8.3 でビルド。Node.js 26。Next.js は使わない）<br>バックエンド：Java 25 ＋ Spring Boot 4.1（Maven、Spring Data JPA、Flyway）<br>データベース：PostgreSQL 18（Docker で動かす）<br>くわしい版は 13.4 |
| 進め方 | 画面・バックエンド・データベースを最初から組み合わせて作る。サーバーを起動して `http://localhost:8080` を開く。まず3つがつながる最小の形を作り、機能を1つずつ足す |
| できること（14機能） | リストの表示・追加、カードの追加・編集・削除（元に戻せる）・移動・並べ替え、自動保存、カードの期限・優先度、期限順・優先度順の並べ替え、カードの検索、カードのラベル（色） |
| 作らないもの | リストの名前変更・削除（今後の拡張案）、ログイン、複数人での利用、複数ボード、元に戻す（カードの削除以外）、スマートフォン表示、インターネットへの公開 |
| 守ること | 動かすときにCDNを使わない、自分のパソコンの中だけで動かす、パスワードをGitに入れない |
| 完成の判断 | 受入テストの「必須」の項目がすべて合格したら完成 |
| まだ決まっていないこと | なし（Q-05 の版はすべて決まった） |
| 次にやること | なし（受入テストは、必須も任意もすべて合格。15.3）。余力があれば、今後の拡張案（19章）から選んで改良する |
