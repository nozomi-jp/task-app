## 5. ユースケース

利用者（自分）が「何のために、どの順番で操作するか」をまとめます。UC-01〜04はボードの操作（UC-05は v2.20 で欠番）、UC-06はアプリの起動と終了です。

### 5.1 利用シナリオ

朝、パソコンでサーバーを起動してボードを開き（UC-06）、今日やることを「ToDo」に書き出す（UC-01）。作業を始めたらカードを「進行中」へ、終わったら「完了」へ動かす（UC-02）。途中で内容が変わったら書き直す（UC-03）。週末に「完了」のカードを片付ける（UC-04）。

### 5.2 ユースケース一覧

| ID | ユースケース | 関係する機能 |
| --- | --- | --- |
| UC-01 | タスクを登録する | F-05、F-10 |
| UC-02 | タスクの進み具合を更新する | F-08、F-09、F-10 |
| UC-03 | タスクの内容を直す | F-06、F-10 |
| UC-04 | 終わったタスクを片付ける | F-07、F-10、F-14 |
| UC-06 | アプリを起動する・終了する | 12章「運用」 |

### 5.3 ユースケースの詳細

**UC-01：タスクを登録する**
- 目的：やることを忘れないように書き出す
- 開始条件：ボードが表示されている
- 基本フロー
  1. 登録したいリストの「+ カードを追加」を押す
  2. 出てきたダイアログに、タイトル（と、必要なら説明・優先度・期限日）を入力し、「保存」を押す（タイトルの欄でEnterキーでもよい）
  3. ダイアログが閉じ、カードがリストの一番下に追加され、自動で保存される
- 代替フロー
  - 2でタイトルに何も入力しない → 「保存」が押せず、Enterキーでも追加されない
  - 2でタイトルに200文字を超えて入力 → 200文字までしか入らない
  - 2で「キャンセル」・Escキー・ダイアログの外をクリック → 追加せずに閉じる
  - 3で保存に失敗（サーバーが止まっているなど） → 画面右上に赤い文字でメッセージが出る。ダイアログは閉じず、入力した内容は残る

**UC-02：タスクの進み具合を更新する**
- 目的：作業の状況に合わせてカードを動かす
- 開始条件：動かしたいカードがある
- 基本フロー
  1. カードをつかむ（カードがマウスについてくる）
  2. 移動先のリストの、置きたい位置まで動かす（置く予定の場所に半透明のカードが入る）
  3. 離すと、カードがその位置に移り、自動で保存される
- 代替フロー
  - 3でリストの外で離した → カードは元の位置に戻る
  - 移動先のリストが空 → 空のリストにも置ける
  - 同じリスト内で動かした → 順番が入れ替わる（優先順位の並べ替え）
  - カードを動かさずに、詳細画面の「ステータス」でリストを選んで保存してもよい → そのリストの一番下へ移る

**UC-03：タスクの内容を直す**
- 目的：書き間違いや内容の変更を反映する
- 開始条件：直したいカードがある
- 基本フロー
  1. カードをクリックする
  2. 詳細画面が開くので、書き換えて「保存」を押す（タイトルの欄でEnterキーでもよい）
  3. 詳細画面が閉じ、内容が変わり、自動で保存される
- 代替フロー
  - 2で「キャンセル」・Escキー・ダイアログの外をクリック → 変えずに閉じる
  - 2でタイトルを全部消す → 「保存」が押せない

**UC-04：終わったタスクを片付ける**
- 目的：不要になったカードを消して、ボードを見やすく保つ
- 開始条件：消したいカードがある
- 基本フロー
  1. カードにマウスを乗せる（右上に「×」が出る）
  2. 「×」を押す
  3. 確認なしですぐ消え、自動で保存される
- 代替フロー
  - 3のあと、まちがいに気づいた → 左下の「元に戻す」を押すか Ctrl + Z → 元の場所に戻る（F-14）

**UC-06：アプリを起動する・終了する**
- 目的：アプリを使い始める、使い終える
- 開始条件：パソコンが起動している（PostgreSQLはパソコンの起動と一緒に自動で動き出す）
- 基本フロー
  1. ターミナルを開き、起動コマンドを入力してサーバーを起動する（12.2）
  2. ブラウザで `http://localhost:8080` を開く
  3. 前回の続きのボードが表示される
  4. 使い終わったら、ターミナルで Ctrl+C を押してサーバーを止める
- 代替フロー
  - 1を忘れて2を開いた → ブラウザに「このサイトにアクセスできません」と出る。1からやり直す
  - サーバーを止めずにパソコンを終了した → 問題ない（保存は操作のたびに終わっているため）
