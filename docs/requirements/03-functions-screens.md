## 6. 機能要件

機能は全部で13個です。優先度「高」の8個がすべて動けば完成とします（詳しくは14章「受入基準」）。

| ID | 対象 | 機能 | 説明 | 優先度 |
| --- | --- | --- | --- | --- |
| F-01 | リスト | 表示 | リストを横に並べて表示する。入りきらない分は下の段へ折り返す | 高 |
| F-02 | リスト | 追加 | 名前を入力して、新しいリストを一番最後に追加する | 高 |
| F-03 | リスト | 名前変更 | リスト名をクリックして書き換える | 中 |
| F-04 | リスト | 削除 | 「×」を押し、確認後にリストと中のカードを削除する | 中 |
| F-05 | カード | 追加 | 各リストの下の「+ カードを追加」でダイアログを開き、タイトル・説明・優先度・期限を入力して、カードを一番下に追加する | 高 |
| F-06 | カード | 編集 | カードをクリックして詳細画面を開き、内容・ステータス・優先度・期限を書き換える | 高 |
| F-07 | カード | 削除 | マウスを乗せると出る「×」で、確認なしで削除する | 高 |
| F-08 | カード | 移動 | ドラッグ&ドロップで、別のリストの好きな位置へ移す | 高 |
| F-09 | カード | 並べ替え | ドラッグ&ドロップで、同じリスト内の順番を入れ替える | 高 |
| F-10 | 共通 | 保存 | 操作のたびに自動保存し、ブラウザを閉じても同じ状態を表示する | 高 |
| F-11 | カード | 期限 | カードに期限（日付）を付ける・変える・外す。付けなくてもよい | 中 |
| F-12 | カード | 優先度 | カードに優先度（高・中・低）を付ける・変える・外す。付けなくてもよい | 中 |
| F-13 | リスト | 期限・優先度順に並べ替え | リスト名の右のボタンで、リストの中のカードを期限順または優先度順に並べ替える | 中 |

### 6.1 共通ルール

追加と変更でルールがそろうように、次のルールをすべての入力欄に当てはめます。

| ルール | リスト名 | カード（タイトル） | カードの説明 |
| --- | --- | --- | --- |
| 文字数の上限 | 20文字 | 200文字 | 1000文字 |
| 空欄 | 追加できない | 追加できない | OK（説明なし） |
| 同じ内容 | OK | OK | OK |
| 改行 | できない | できない | **できる** |
| 確定 | Enterキー | Enterキー、またはダイアログの「保存」ボタン | ダイアログの「保存」ボタン（Enterは改行） |
| やめる | Escキー | Escキー、またはダイアログの「キャンセル」ボタン | Escキー、「キャンセル」ボタン |
| 入力欄の外をクリック | 追加のときは**やめる**、名前変更のときは**確定** | ダイアログの外をクリックすると**やめる**（追加・詳細とも） | **やめる** |

リスト名の入力欄の外をクリックしたとき、追加は「やめる」、変更は「確定」にそろえます。追加の途中で外をクリックするのは「やっぱりやめた」ことが多く、変更の途中で外をクリックするのは「書き終えた」ことが多いためです。
カードは追加も詳細（変更）もダイアログで行うので、ダイアログの外をクリックしたときはどちらも「やめる」にします。ダイアログでは、保存するときに「保存」ボタンを押すのがはっきりしているためです（v2.10）。

日本語入力で変換を確定するための Enter では、確定（追加・保存）しません。

### 6.2 各機能の詳細

**F-01：リストの表示**
- 初めて開いたときは「ToDo」「進行中」「完了」の3つのリストを表示する
- サンプルのカードは入れない（最初はカードなし）
- 画面の幅に入りきらないリストは下の段へ折り返し、画面は下にスクロールする

**F-02：リストの追加**
- リストの並びの最後にある「+ リストを追加」を押すと、入力欄が出る
- 確定すると、新しいリストを一番最後に追加する
- Escキー、または入力欄の外をクリックすると、追加をやめる
- リストの数に上限はない

**F-03：リストの名前変更**
- リスト名をクリックすると、その場で入力欄に変わる
- Escキーを押すと、元の名前に戻す
- 全部消して確定したときは、何も言わずに元の名前に戻す
- 最初からある3つのリストも、ほかのリストと同じく名前を変えられる

**F-04：リストの削除**
- リスト名の右の「×」を押すと削除する
- カードが入っているときは、ブラウザ標準の確認画面を出す。文面にはリスト名とカードの枚数を入れる（例：「『ToDo』を削除しますか？中のカード3枚も削除されます」）
- 空のリストは、確認なしですぐ削除する
- リストが全部なくなってもよい（「+ リストを追加」だけが残る）

**F-05：カードの追加**（v2.9 でダイアログに変更。講座の先生の画面に合わせた）
- リストの一番下の「+ カードを追加」を押すと、画面の真ん中に「タスクを追加」のダイアログが出る。後ろは暗くなり、操作できなくなる
- 入力する項目
  - タイトル（必須、200文字まで、改行なし）
  - 説明（なくてもよい、1000文字まで、改行できる）
  - 優先度（高・中・低から1つ選ぶ。最初は「中」が選ばれている）
  - 期限日（なくてもよい。カレンダーから選ぶ）
- 「保存」ボタン、またはタイトルの欄で Enter を押すと、カードをリストの一番下に追加して、ダイアログを閉じる
- タイトルが空（空白だけを含む）のあいだは、「保存」ボタンを押せない
- 「キャンセル」ボタン、Escキー、またはダイアログの外をクリックすると、追加せずに閉じる
- 保存に失敗したときは、ダイアログを閉じずに、入力した内容を残す（右上に赤い字で理由を出す）
- カードには、タイトルの下に説明を小さく表示する（長いときは3行まで）

**F-06：カードの編集（詳細画面）**（v2.10 で詳細画面に変更。講座の先生の画面に合わせた）
- カードをクリック（またはキーボードで選んで Enter）すると、「タスクの詳細」のダイアログ（モーダル）が出る。中身は追加のダイアログ（F-05）と同じ形で、今の内容が入っている
- 変えられる項目：タイトル、説明、**ステータス**（どのリストに入れるか）、優先度（高・中・低・**なし**）、期限日（空にすると期限を外す）
- 「保存」ボタン、またはタイトルの欄で Enter を押すと保存して閉じる。変えた内容は、すぐカードに反映される
- ステータスを変えて保存すると、カードはそのリストの一番下へ移る（移動元のリストのすき間は詰める）
- タイトルが空（空白だけを含む）のあいだは、「保存」ボタンを押せない（削除は別の操作で行う）
- 「キャンセル」ボタン、Escキー、またはダイアログの外をクリックすると、変えずに閉じる
- 保存に失敗したときは、ダイアログを閉じずに、入力した内容を残す（右上に赤い字で理由を出し、ボードを読み込み直す）
- ドラッグ（F-08・F-09）と区別するため、カードを少し動かしたらドラッグ、動かさずに離したらクリックとして扱う

**F-07：カードの削除**
- カードにマウスを乗せたときだけ、カードの右端に「×」を表示する
- 「×」を押すと、確認なしですぐ削除する。データベースから行ごとなくなる**物理削除**なので、元に戻せない（API-07）
- 「×」を押しても、詳細画面は開かず、ドラッグにもならない。キーボードで「×」を選んで Enter を押しても削除できる
- 1枚消した直後（0.5秒）に押された「×」は無視する。カードが詰まって上がってくるので、うっかりダブルクリックしたときに次のカードまで消さないため
- 失敗したら、右上に赤い字で理由を出し、ボードを読み込み直す

**F-08：カードの移動**
- カードをつかんで、別のリストのカードとカードの間など、好きな位置に置ける
- カードが1枚もないリストにも置ける
- つかんでいる間は、カードがマウスについてくる。置く予定の場所には半透明のカードが入り（ほかのカードはよけて空ける）、カードを持って上に来ているリストは点線で囲む（v2.11 で「置く位置に線」から変更。dnd-kit の並べ替えの見せ方に合わせた）
- リストの外で離したとき、または Esc キーを押したときは、元の場所に戻す
- 少し（5px 以上）動かしたらドラッグ、動かさずに離したらクリック（詳細画面を開く、F-06）として扱う
- キーボードでは、カードを選んで Space でつかみ、矢印キーで動かし、Space で置く（Enter は詳細画面を開く）
- 置いたらすぐ保存する（API-08）。保存に失敗したら、右上に赤い字で理由を出し、ボードを読み込み直す
- 別のリストへ移すことは、ステータスの更新でもある（詳細画面の「ステータス」と同じ結果になる）

**F-09：カードの並べ替え**
- F-08と同じ操作と見た目で、同じリスト内の順番を入れ替える

**F-10：保存**
- 追加・編集・削除・移動のたびに自動で保存する（ボード全体を保存するボタンはない。カードの追加・詳細のダイアログには、その入力を確定する「保存」ボタンがある）
- ブラウザを閉じても、パソコンを再起動しても、次に開いたときに同じ状態を表示する
- 初めて使うときは、最初の3つのリストの状態から始める
- 保存先はデータベース。保存のしかたは9章と10章に従う
- 別のブラウザで開いても、同じ状態を表示する

**F-11：期限**
- カードの文字と同じ行の右側に、期限の印をいつも表示する。期限がないカードには、薄い「期限」の印を出す
- 期限は、追加のダイアログ（F-05）と詳細画面（F-06）の「期限日」で付ける・変える。ブラウザ標準の日付の入力欄（カレンダー付き）を使う（v2.10 で、印をクリックして変える形から変更）
  - 詳細画面で期限日を空にして保存すると、期限を外す
- 表示は「11/25」の形。今年でない日付は「2027/1/5」の形にする
- 期限が今日のカードは黄色、期限を過ぎたカードは赤で表示する。それ以外はグレー
- 過去の日付も設定できる

**F-12：優先度**
- カードの文字と同じ行の右側（期限の右）に、優先度の印をいつも表示する。優先度がないカードには、薄い「優先度」の印を出す
- 優先度は、追加のダイアログ（F-05、「高」「中」「低」から選ぶ。最初は「中」）と詳細画面（F-06、「高」「中」「低」「なし」から選ぶ。今の優先度が選ばれている）で付ける・変える（v2.10 で、印をクリックしてメニューから選ぶ形から変更）
- 色は、高＝赤、中＝オレンジ、低＝青

**F-13：期限・優先度順に並べ替え**
- リスト名の右に「期限 ⇅」「優先度 ⇅」の2つのボタンをいつも出す（リスト削除の「×」を作るときは、その左）。マウスを乗せると「期限が近い順に並べ替え」のように、押したときの動きの説明が出る（v2.14 で、「⇅」を押してメニューを開く形から変更）
- 1回押すと、期限は近い順・優先度は高い順に並び、矢印が ▲ になる。**もう一度押すと反対の順**（遠い順・低い順）で、矢印が ▼ になる。その順に並んでいないときは ⇅（v2.14 で追加。v1.4 では「逆向きは入れない」としていた）
  - 「もう一度」かどうかは、今のカードの並びを見て決める。再読み込みやドラッグのあとでも向きがおかしくならない
- 押すと、そのリストの中のカードを**その時に1回だけ**並べ替える。並べ替えた結果は保存する
  - その後もドラッグ&ドロップで自由に動かせる（F-09）
  - あとから追加したカードは、これまでどおり一番下に入る
- 期限が近い順：期限が早いものが上。遠い順はその反対。期限がないカードは、どちらの向きでも一番下
- 優先度が高い順：高→中→低の順。低い順はその反対。優先度がないカードは、どちらの向きでも一番下
- 期限や優先度が同じカードどうしは、並べ替える前の順番のまま

## 7. 画面設計

### 7.1 画面一覧

画面はボード画面1つだけです。入力欄やメッセージは、別の画面に切り替えずにボード画面の中で表示します。

| ID | 名前 | 種類 | 表示するタイミング | 関係する機能・ユースケース |
| --- | --- | --- | --- | --- |
| SC-01 | ボード画面 | 画面 | アプリを開いたとき（唯一の画面） | F-01〜F-13、UC-01〜05 |
| SC-01-a | リスト名の入力欄 | ボード画面の中の部品 | 「+ リストを追加」やリスト名を押したとき | F-02、F-03、UC-05 |
| SC-01-b | カードの追加ダイアログ／カードの詳細画面（タイトル・説明・優先度・期限日。詳細画面はステータスも） | ボード画面の上に出るダイアログ（モーダル） | 「+ カードを追加」を押したとき／カードをクリックしたとき | F-05、F-06、F-11、F-12、UC-01、UC-03 |
| SC-01-c | 保存エラーの表示 | ボード画面の中の部品（右上） | 保存に失敗したとき | F-10、NFR-14 |
| SC-01-f | 並べ替えのボタン（期限・優先度） | ボード画面の中の部品 | いつも（リスト名の右） | F-13 |
| DL-01 | リスト削除の確認 | ブラウザ標準の確認画面 | カードが入ったリストの「×」を押したとき | F-04、UC-05 |

※ SC-01-d（期限の入力欄とカレンダー）・SC-01-e（優先度のメニュー）は、v2.10 で詳細画面（SC-01-b）にまとめたため欠番。

### 7.2 ボード画面（SC-01）のレイアウト

上部にボード名、その下にリストが横に並びます。入りきらないリストは下の段へ折り返します。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ マイボード                                                 変更は自動保存 │
└──────────────────────────────────────────────────────────────────────────┘
┌─────────────────────────┐ ┌─────────────────────────┐ ┌ ─ ─ ─ ─ ─ ─ ┐
│ ToDo               ⇅ × │ │ 進行中             ⇅ × │   + リストを追加
│┌───────────────────────┐│ │┌───────────────────────┐│ └ ─ ─ ─ ─ ─ ─ ┘
││要件定義を書く 11/18 高 ││ ││環境を用意    11/17 低 ││
│└───────────────────────┘│ │└───────────────────────┘│
│┌───────────────────────┐│ │┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐│
││画面を作る    11/23 中 ├──→ ここへドロップ          │
│└───────────────────────┘│ │└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘│
│┌───────────────────────┐│ │                         │
││課題を確認  期限 優先度││ │                         │
│└───────────────────────┘│ │                         │
│+ カードを追加            │ │+ カードを追加            │
└─────────────────────────┘ └─────────────────────────┘
```

※ 図のカードは操作のイメージを示す例です。実際には、初めて開いたときにカードは入っていません。

- カードの右側の「11/18」が期限、「高」が優先度の印（F-11・F-12）。今日が11/18のとき、「11/18」は黄色、「11/17」は赤で表示する
- 「期限」「優先度」の薄い印は、まだ設定していないことを表す
- リスト名の右に、並べ替えのボタン「期限 ⇅」「優先度 ⇅」が並ぶ（F-13。図では「⇅」と省略）

右上の「変更は自動保存」は、保存に失敗したときだけ、赤い文字のメッセージに変わります。

| 失敗の例 | メッセージ |
| --- | --- |
| サーバーが止まっている、つながらない | 保存できませんでした（サーバーに接続できません） |
| 入力がルールに合わないなど、サーバーがエラーを返した | 保存できませんでした（サーバーが返した理由） |

どちらの場合も、メッセージを出したあとにボードを読み込み直し、データベースの本当の状態を表示します（10章）。

| 操作 | やり方 |
| --- | --- |
| カードを追加 | リスト下の「+ カードを追加」を押し、ダイアログでタイトル（と、必要なら説明・優先度・期限日）を入力して「保存」（タイトルの欄で Enter でもよい） |
| カードを編集 | カードをクリックして詳細画面を開き、書き換えて「保存」（タイトルの欄で Enter でもよい） |
| ステータスを変える | 詳細画面の「ステータス」でリストを選んで「保存」（そのリストの一番下へ移る）。またはカードをつかんで別のリストへ動かす |
| カードを削除 | カードにマウスを乗せると出る「×」を押す |
| カードを移動・並べ替え | カードをつかんで、置きたい位置で離す |
| 期限を付ける・変える・外す | 詳細画面の「期限日」で選んで「保存」（空にすると外す） |
| 優先度を付ける・変える・外す | 詳細画面の「優先度」で選んで「保存」（「なし」で外す） |
| 期限順・優先度順に並べ替え | リスト名の右の「期限」（近い順）か「優先度」（高い順）を押す。もう一度押すと反対の順 |
| リストを追加 | 右端の「+ リストを追加」を押し、名前を入力してEnter |
| リスト名を変更 | リスト名をクリックして書き換え、Enter |
| リストを削除 | リスト名の右の「×」を押す（カードがあるときは確認でOK） |
